# Hands on Labs

This folder contains scenario-based Cisco Packet Tracer practice that follows the same teaching pattern as the Villa University and Nova Care assignments. The theory lessons remain in `Network_Engineering_Foundation_20_Lessons/`; these labs give students practical work that matches each lesson.

Each lesson-aligned lab is separated into three files:

- `Topology.md` explains the physical topology, devices, cabling, and addressing plan.
- `Problem.md` gives the student-facing scenario, requirements, tasks, and deliverables.
- `Solution.md` gives the instructor/student solution with step-by-step configuration, copyable Cisco IOS commands, verification, and troubleshooting.
