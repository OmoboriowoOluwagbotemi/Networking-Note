# Hands on Labs

This folder contains scenario-based Cisco Packet Tracer practice that follows the same teaching pattern as the Villa University and Nova Care assignments. The theory lessons remain in Network_Engineering_Foundation_20_Lessons/; these labs give students practical work that matches each lesson.

Each lab includes a scenario, topology requirement, addressing plan, step-by-step Packet Tracer work, copyable Cisco IOS commands, verification checks, troubleshooting guidance, and student deliverables.
