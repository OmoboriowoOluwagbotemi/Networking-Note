# Hands on Labs

This folder contains scenario-based Cisco Packet Tracer assignments. The structure follows the same style as the Villa University and Nova Care case studies: each assignment is its own folder, and each folder contains a topology document, a problem document, and a solution document.

The theory lessons remain in `Network_Engineering_Foundation_20_Lessons/`. These hands-on cases give students practical Packet Tracer work that aligns with the lessons while using different real-world contexts.
